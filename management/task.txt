### Interval 6: Micro-Learning Content Engine (Next)
- [x] **Task 6.1 (Obj i, v): Content Ingestion Worker (Zero-Key Resilient)**
  - Multi-source Python worker script (`backend/scripts/ingest_content.py`) requiring zero external paid API keys:
    1. Dev.to API (top developer tutorials & architectural takeaways)
    2. StackExchange API (StackOverflow, MedicalSciences, Law, Money/Finance Q&A)
    3. Wikipedia REST API (encyclopedic concept foundations)
    4. Hacker News via Algolia API (high-signal engineering guides)
    5. YouTube Video Engine (keyless public search with optional YouTube v3 API upgrade)
  - 3-Gate validation pipeline:
    1. Engagement gate (Dev.to reactions >= 20, SE votes >= 5 with accepted answer, HN points >= 30)
    2. Blacklist gate (reject low-value titles: "My thoughts on...", "Rant", "Why I left...", "Drama")
    3. Tag intersection gate (verified match against `skills` table in Supabase)
- [x] **Task 6.2 (Obj i, v): Content Atomization & Quiz Generation**
  - NLP summarization: condense content to 3-bullet / <150 word summary
  - LLM-driven 5-question MCQ JSON generation per content item
  - Content vector (384-dim) computed and stored in `micro_content.embedding`
- [x] **Task 6.3 (Obj ii, v): Two-Stage Hybrid Recommendation Feed**
  - Stage 1: pgvector coarse filter on `micro_content` → top 30 by cosine similarity to user skill gap vector (with relational fallback)
  - Stage 2: FastAPI re-ranker applying difficulty penalty, breadth priority, `source_trust_score` multiplier → top 5
  - New `/recommendations` feed integrated into frontend with embedded quiz UI
- [x] **Task 6.4 (Obj v): Quiz Interaction & Skill Progression**
  - Quiz rendered dynamically from `quizzes` JSONB column
  - Correct answers → `proficiency` +10% update in `user_skills`
  - Skill status auto-updated to `Mastered` at 100%
  - "Ask MENTOR" fallback summon on repeated quiz failure
